# AAC Factory v0.3 — Runtime Truth + Integration Reality

v0.3 turns the S6 compiler/runtime from "runnable shadow agent" into a stricter truth contract: if a package claims a behavior is certifying, the compiler must prove the runtime can enforce it or block the build/promotion path.

## Release promise

Every compiled agent-card claim is one of three things:

1. enforced by generated runtime code;
2. explicitly marked non-certifying/advisory; or
3. blocked before compile, certification, promotion, or improver adoption.

## What changed

- **Route truth:** `workflow.edges[].condition` must parse against the small deterministic grammar. Prose like `low confidence` now fails compile.
- **Gate truth:** certifying output gates must parse against the executable gate grammar. Example: `required_if(decision == "include", section)`.
- **Model truth:** LLM adapters return structured metadata with `requested_model`, `actual_model`, `model_verified`, and `verification_source`.
- **Telemetry truth:** token/cost fields use `unknown` when unavailable. The runtime no longer records fake zero usage.
- **Improver truth:** replay/stub evals can queue proposals but cannot auto-adopt model changes. Adoption requires real executor evidence.
- **Local endpoint truth:** local OpenAI-compatible endpoints are first-class for mlx-lm, LM Studio, and vLLM-style `/v1/chat/completions` servers.
- **Hermes cron integration:** `runtime_target: hermes-cron` emits a no-agent wrapper plus cron creation metadata/snippet.
- **Batch truth:** finite `candidates: [...]` inputs emit a batch parent run plus child run cards.
- **TBR governance truth:** Translator/Bouncer/Recorder proof blocks are generated on workflow/node cards, audited by QA, compiled into `nodes.json`, and emitted on run cards as certification evidence.

## Gate grammar in v0.3

Supported output gate rules:

- `required(field)`
- `required_if(condition, field)`
- `not_null(field)`
- `enum(field, [values])`
- `min(field, value)`
- `max(field, value)`
- `regex_absent(field, pattern_name)`
- `source_required_if(condition)`
- `confidence_floor_by_action_consequence(...)`

Supported route conditions:

- `always`
- `field == value`, `field != value`, `field >= value`, `field < value`
- `field in [a, b, c]`

## Certification implications

A run can still execute in shadow/debug mode with unknown usage or unverified model identity, but those facts are carried as certification blockers. Cost-rank adoption and cheaper-model claims require real usage evidence. Model-quality claims require verified model identity.

## Regression coverage

`tests/test_runtime_truth.py` covers the external-trial failure modes:

- prose route/gate compile refusal;
- `required_if(decision == "include", section)` runtime enforcement;
- `claude-code-headless` passing `--model` and parsing JSON usage/model metadata;
- local OpenAI-compatible endpoint routing;
- Hermes cron wrapper generation/dry run;
- batch parent/child run-card emission;
- research filler regex gate behavior.
